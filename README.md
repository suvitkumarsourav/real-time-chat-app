# Real-Time Chat Application

**Author:** Suvit Kumar Sourav

---

## Project Overview

This is a **full-stack real-time chat application** built with **React, Node.js, Express, and Socket.io**.  
It allows users to:  

- Join multiple chat rooms  
- Send and receive **real-time messages**  
- See a **list of active users** in each room  
- Receive **room notifications** for new messages  
- Optionally login as **Guest** (Firebase Google login can be added)  
- Responsive and user-friendly interface

---

## Features

- Multi-room chat support  
- Active users list and live notifications  
- Typing preview for real-time feedback  
- Clean and responsive UI/UX  
- Guest login support (Google login optional)

---
